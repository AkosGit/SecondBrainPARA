# Inbox

Staging lane for captured `Type: Source` notes awaiting digest. Flat by design.
Classification (area/topic tags) happens on the extracted Idea note, not here.
See [[Information Intake — v1 Implementation Plan]].

## Queue status
```dataviewjs
const inbox = dv.pages('"Inbox"').where(p => p.Type === "Source" && p.reading_status !== "integrated");
const n = inbox.length;
if (n > 10) {
  dv.paragraph(`⚠️ **${n} sources awaiting digest — digest or delete before capturing more.** (cap: 10)`);
} else {
  dv.paragraph(`${n} source(s) awaiting digest. (cap: 10)`);
}
```

## Awaiting digest
```dataview
TABLE WITHOUT ID file.link AS "Source", reading_status AS "Status", author AS "Author", (date(today) - file.cday).day AS "Age (days)"
FROM "Inbox"
WHERE Type = "Source" AND reading_status != "integrated"
SORT file.ctime ASC
```

## Stale (older than 14 days)
```dataview
TABLE WITHOUT ID file.link AS "Source", (date(today) - file.cday).day AS "Age (days)"
FROM "Inbox"
WHERE Type = "Source" AND reading_status != "integrated" AND (date(today) - file.cday).day > 14
SORT file.ctime ASC
```

## Integrated
```dataview
TABLE WITHOUT ID file.link AS "Source", row["ideas-extracted"] AS "Ideas"
FROM "Inbox"
WHERE Type = "Source" AND reading_status = "integrated"
SORT file.mtime DESC
```

## Everything else in Inbox
```dataview
TABLE WITHOUT ID file.link AS "Note", Type AS "Type"
FROM "Inbox"
WHERE file.name != "00000" AND Type != "Source"
SORT file.ctime ASC
```
